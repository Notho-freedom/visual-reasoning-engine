A React/TypeScript application built with Vite and a modern component stack. The repository currently uses Supabase for backend services and Vitest for automated tests.

## 🛠️ Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Radix UI / shadcn-style components
- Supabase
- React Query
- React Hook Form + Zod
- Vitest + Testing Library

## 🚀 Development

```bash
npm install
npm run dev
```

## 🧪 Quality checks

```bash
npm run lint
npm run test
npm run build
```

## 📌 Status

Active development. The repository is currently structured as a Vite/React application; product-specific documentation will be expanded as the engine's capabilities stabilize.
